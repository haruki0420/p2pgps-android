# P2P GPS Android Sender

Android の現在地を Bluetooth で iPad に送るアプリです。

## 使い方

1. APK をインストールする
2. 位置情報・Bluetooth・通知を許可する
3. 「送信を開始」を押す
4. iPad 側で送信元を選ぶ

## 必要なもの

- Android 8.0 以降・Bluetooth 対応端末
- 受信側の iPad に P2P GPS の受信アプリと準備（pairing file / LocalDevVPN / DDI）
- 近距離・1 対 1 接続
